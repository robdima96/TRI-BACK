# Outputs

Generated by `screen_medqa.py`, `apply_clinician.py`, and `run_patient.py`.

| `briefing/MedQA_screening_briefing.pptx` | PI / team deck (screening done + clinician next) | no |
| `screening/audit_*.md` / `.json` | PRISMA counts, drop reasons, grid | no |
| `screening/sample_manifest_*.json` | Provisional sample IDs + stem hashes | no |
| `screening/clinician_review_*.csv` | Stage 3 coding sheet (auto-eligible only) | **yes** |
| `screening/all_rows_*.jsonl` | Every item with stage + drop_reason | **yes** |
| `cards/<run_id>/` | Stub / AgentClinic-mapped OSCE cards (pre-clinician) | **yes** |
| `dialogues/` | Echo or live patient-agent transcripts | usually no (derived speech) |
| `briefing/MedQA_screening_briefing.pptx` | PI / team deck (screening done + clinician next) | no |

Stem-containing files are gitignored. Keep `audit_*.md` for methods reporting.
