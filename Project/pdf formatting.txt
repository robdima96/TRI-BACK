DigiMSKbot — PDF formatting (MONTH1_IMPLEMENTATION_PLAN.pdf, Data-Safety-Privacy-Checklist.pdf)
=============================================================================================

Source of truth: bot/docs/digimsk_pdf.py
- Month 1 plan: python docs/render_month1_pdf.py
- Data safety checklist: python docs/render_checklist_pdf.py

Page
----
- Page size: US Letter (reportlab.lib.pagesizes.letter)
- Margins (all sides): 0.85 inch (left, right, top, bottom)
- Single page template used for every page (BaseDocTemplate + one PageTemplate)

Background
----------
- Fill: #26262B (dark charcoal / near-grey; not pure black)
- Applied: full page rectangle at the start of each page (PageTemplate.onPage)

Typography (ReportLab Paragraph styles)
---------------------------------------
- Family: Merriweather (Google Fonts; static TTFs instanced from VF in docs/fonts/)
- Registered names: Merriweather, Merriweather-Bold, Merriweather-Italic, Merriweather-BoldItalic
- Body text color: #FFFFFF (white)

Sizes / styles
- Document title: Merriweather 18 pt, leading 22, white, left-aligned
- Section headings (H2, uppercased in output): Merriweather-Bold 11 pt, leading 14, white; space before 12, after 6
- Body: Merriweather 10 pt, leading 13, white; space after 5
- Bullets: Merriweather 10 pt; first level left indent 16; nested left indent 30
- Inline code (backticks in Markdown): same Merriweather face as body (not monospace)
- Footer: Merriweather 9 pt, white

Accent rules (HRFlowable)
-------------------------
- Color: #4A9EFF
- Under document title: thickness 0.5 pt; space after 10
- Above each section block: thickness 1.25 pt; space before 4, after 6

Header (PageTemplate.onPage — with background, every page)
------------------------------------------------------------
- Top vertical position: 0.55 inch below top of page (y = page height − 0.55 inch)
- Horizontal margin from left edge: 0.85 inch
- Text: "DigiMSK Chatbot - Ardern Lab UBC" (Merriweather 9 pt, white)

Footer (PageTemplate.onPageEnd — after page content, every page)
-----------------------------------------------------------------
- Bottom vertical position: 0.55 inch from bottom of page
- Horizontal margin from left/right edges: 0.85 inch
- Bottom-left:  "version date: [today's date in format yyy.mm.dd]"
- Bottom-right: "-- <page> of <total> --" (right-aligned)

Engine notes
------------
- Use BaseDocTemplate (not SimpleDocTemplate) so SimpleDocTemplate.build does not inject
  separate First/Later templates that replace custom PageTemplate.onPage handlers.
- PageTemplate.onPage: background fill + header line (runs before frame content).
- PageTemplate.onPageEnd: footer only (runs after frame content; same on all pages).

Optional Python dependencies (see bot/pyproject.toml [project.optional-dependencies] pdf)
----------------------------------------------------------------------------------------
- reportlab, pypdf, fonttools
