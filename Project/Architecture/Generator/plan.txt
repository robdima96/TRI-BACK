Component: Generative LLM
Source: generator.png

Core function:
- Produce clinically conservative, terminology-precise responses.
- Optimize instruction-following model behavior with preference training.

Planned models/approach:
- Llama-3-8B-Instruct as base.
- DPO-RL style preference optimization.
- Chain-of-thought referenced in concept.

Data (from draft):
- Paired preference dataset for DPO (~500 samples).

Tools (from draft):
- HuggingFace or other instruct-tuned model stack.
- HuggingFace TRL libraries.

Compute (from draft):
- High compute requirements.
- Use PEFT/LoRA for efficient adaptation.

Enhancements added:
- Expand DPO preference data beyond ~500 pairs for stability and domain coverage.
- Define safety policy tiers (inform, refuse, escalate) for high-risk clinical prompts.
- Add factuality and groundedness checks against RAG citations before final response.
- Add evaluation rubric for conservatism, calibration, harmful reassurance, and hallucination rates.
- Define strict output schema consumed by downstream orchestrator and synthesizer components.

Cross-cutting requirements:
- Clinical safety boundaries and mandatory human handoff triggers.
- Unified evaluation framework (technical, clinical, and safety metrics).
- Privacy/compliance controls (retention limits, access control, auditability).
- Deployment SLOs and cost envelope tracking.
- Red-team tests for prompt injection, unsafe advice, and uncertainty handling.
